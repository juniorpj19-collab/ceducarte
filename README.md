# Ceducarte Onepage Plugin

Plugin WordPress para criação de **sites onepage institucionais totalmente personalizáveis**, desenvolvido inicialmente para o CEDUCARTE, mas projetado para ser reutilizado por **outras organizações, projetos e instituições**.

O plugin fornece um **modelo visual completo de site**, com edição centralizada via painel administrativo, sem dependência de page builders.

---

## 🎯 Objetivo do Plugin

- Criar um **modelo padrão de site onepage**
- Permitir **personalização total pelo painel**
- Facilitar reutilização para outros projetos no futuro
- Evitar dependência de temas ou construtores externos
- Manter performance, responsividade e padrão WordPress

---

## 🧩 Estrutura do Site (Blocos)

O site é composto por blocos modulares:

- **Header / Menu com âncoras**
- **Hero (destaque principal)**
- **Vídeos**
- **Blocos visuais (inspirados em PDF, mas em HTML)**
- **Projetos / Cards**
- **Rodapé**

Cada bloco pode ser:
- ativado ou desativado
- ter textos, imagens, cores e links alterados pelo painel

---

## ⚙️ Personalização via Painel

O plugin cria uma página própria no admin do WordPress:

**Ceducarte Onepage → Configurações**

Permite editar:
- Nome da marca
- Logo
- Paleta de cores
- Menu com âncoras
- Textos do Hero
- Botões
- Vídeos
- Blocos visuais
- Cards de projetos
- Rodapé

Tudo sem editar código.
